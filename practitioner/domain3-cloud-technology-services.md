# ☁️ Domain 3: Cloud Technology and Services | Tecnologia e Serviços da Nuvem

> 🇬🇧 This section covers core AWS services, global infrastructure, and cloud deployment models.  
> 🇧🇷 Esta seção cobre os serviços centrais da AWS, a infraestrutura global e os modelos de implantação em nuvem.

---

## ✅ 3.1 – AWS Global Infrastructure | Infraestrutura Global da AWS

### 🇬🇧
- **Regions:** Physical locations with multiple Availability Zones.
- **Availability Zones (AZs):** Isolated data centers within a region.
- **Edge Locations:** For caching and content delivery (CloudFront).
- **Local Zones / Wavelength Zones:** Extend AWS to metro areas and telecom networks.

### 🇧🇷
- **Regiões:** Locais físicos com múltiplas Zonas de Disponibilidade.
- **Zonas de Disponibilidade (AZs):** Data centers isolados dentro de uma região.
- **Edge Locations:** Para cache e entrega de conteúdo (CloudFront).
- **Zonas Locais / Wavelength:** Expandem a AWS para áreas metropolitanas e redes 5G.

---

## ✅ 3.2 – Core AWS Services | Serviços Centrais da AWS

### 🇬🇧
#### Compute:
- **EC2:** Virtual servers.
- **Lambda:** Serverless functions.
- **Elastic Beanstalk:** Platform as a Service (PaaS).

#### Storage:
- **S3:** Scalable object storage.
- **EBS:** Block storage for EC2.
- **Glacier:** Long-term archival storage.

#### Networking:
- **VPC:** Virtual Private Cloud.
- **Route 53:** DNS service.
- **CloudFront:** CDN service.

#### Databases:
- **RDS:** Managed relational databases.
- **DynamoDB:** NoSQL database.
- **Redshift:** Data warehouse.

#### Application Integration:
- **SNS:** Notification service.
- **SQS:** Message queueing.
- **Step Functions:** Workflow automation.

### 🇧🇷
#### Computação:
- **EC2:** Servidores virtuais.
- **Lambda:** Funções serverless.
- **Elastic Beanstalk:** Plataforma como serviço (PaaS).

#### Armazenamento:
- **S3:** Armazenamento de objetos escalável.
- **EBS:** Armazenamento em blocos para EC2.
- **Glacier:** Armazenamento para arquivamento de longo prazo.

#### Rede:
- **VPC:** Nuvem virtual privada.
- **Route 53:** Serviço de DNS.
- **CloudFront:** Rede de entrega de conteúdo (CDN).

#### Bancos de Dados:
- **RDS:** Banco de dados relacional gerenciado.
- **DynamoDB:** Banco de dados NoSQL.
- **Redshift:** Armazém de dados (data warehouse).

#### Integração de Aplicações:
- **SNS:** Serviço de notificação.
- **SQS:** Fila de mensagens.
- **Step Functions:** Automatização de workflows.

## ✅ 3.3 – Cloud Deployment Models | Modelos de Implantação em Nuvem

### 🇬🇧
- **Public Cloud:** AWS infrastructure shared among customers.
- **Private Cloud:** Dedicated infrastructure (on-premises or on AWS Outposts).
- **Hybrid Cloud:** Combination of on-premises and AWS resources.

### 🇧🇷
- **Nuvem Pública:** Infraestrutura AWS compartilhada entre clientes.
- **Nuvem Privada:** Infraestrutura dedicada (on-premises ou AWS Outposts).
- **Nuvem Híbrida:** Combinação de recursos locais e da AWS.
