# ⚠️ AWS Solutions Architect – Traps & Tips | Pegadinhas e Dicas

> 🇬🇧 This guide highlights common traps, confusing topics, and practical tips to avoid mistakes during the exam.  
> 🇧🇷 Este guia destaca pegadinhas, tópicos confusos e dicas práticas para evitar erros durante o exame.

---

## ⚠️ Common Traps | Pegadinhas Comuns

### ❌ 1. Misunderstanding RTO vs RPO  
**🇬🇧 RTO = how long to recover. RPO = how much data can be lost.**  
**🇧🇷 RTO = quanto tempo para recuperar. RPO = quanto de dados pode ser perdido.**

### ❌ 2. Confusing S3 Storage Classes  
**🇬🇧 S3 Standard IA ≠ Glacier. Glacier is for archival, not frequent access.**  
**🇧🇷 S3 Standard IA ≠ Glacier. Glacier é para arquivamento, não acesso frequente.**

### ❌ 3. Root User Use  
**🇬🇧 Root user should only be used for initial setup.**  
**🇧🇷 O usuário root deve ser usado apenas na configuração inicial.**

### ❌ 4. VPC Peering ≠ Transit Gateway  
**🇬🇧 VPC peering is 1:1; Transit Gateway allows multiple VPCs.**  
**🇧🇷 Peering é ponto a ponto; o Transit Gateway conecta várias VPCs.**

### ❌ 5. EBS ≠ S3  
**🇬🇧 EBS = block storage for EC2. S3 = object storage for general use.**  
**🇧🇷 EBS = armazenamento em blocos para EC2. S3 = armazenamento de objetos em geral.**

## ✅ Pro Tips | Dicas Estratégicas

### ✅ 1. Draw Network Topologies  
**🇬🇧 Visualizing VPCs, subnets, and routes helps during scenario questions.**  
**🇧🇷 Visualizar VPCs, subnets e rotas ajuda em questões de cenários.**

### ✅ 2. Understand Auto Scaling Logic  
**🇬🇧 Know the triggers (CPU, ALB, SQS queue depth) for scaling.**  
**🇧🇷 Saiba os gatilhos (CPU, ALB, fila SQS) para escalonamento automático.**

### ✅ 3. Know the DR Models  
**🇬🇧 Backup & Restore, Pilot Light, Warm Standby, Multi-Site.**  
**🇧🇷 Backup & Restore, Pilot Light, Warm Standby, Multi-Site.**

### ✅ 4. Use Tags in Cost Questions  
**🇬🇧 Tagging resources helps track costs and organize environments.**  
**🇧🇷 Taggear recursos ajuda a rastrear custos e organizar ambientes.**

### ✅ 5. Time Management During the Exam  
**🇬🇧 Don’t get stuck. Flag difficult questions and return later.**  
**🇧🇷 Não trave. Marque perguntas difíceis e volte depois.**

> 🎯 Mantenha a calma, confie na sua preparação e pense com lógica de produção!
