## 🔐 Domain 1: Design Secure Architectures

### ❓ Question 1  
**🇬🇧 Which two actions help improve account security?**  
**🇧🇷 Quais duas ações ajudam a melhorar a segurança da conta?**

A) Use root account for daily tasks  
B) Enable multi-factor authentication (MFA)  
C) Use IAM roles for EC2  
D) Disable CloudTrail  
E) Share access keys via email

**✅ Answers: B, C**  
**🇬🇧 Explanation:** MFA and IAM roles enhance security by minimizing exposure of sensitive credentials.  
**🇧🇷 Explicação:** MFA e funções IAM aumentam a segurança ao minimizar a exposição de credenciais sensíveis.

## ♻️ Domain 2: Design Resilient Architectures

### ❓ Question 2  
**🇬🇧 Which two services are recommended for high availability across multiple AZs?**  
**🇧🇷 Quais dois serviços são recomendados para alta disponibilidade entre várias AZs?**

A) Amazon EC2 Auto Scaling  
B) Amazon RDS Multi-AZ  
C) AWS CloudTrail  
D) AWS IAM  
E) AWS Shield

**✅ Answers: A, B**  
**🇬🇧 Explanation:** Auto Scaling and RDS Multi-AZ provide redundancy across availability zones.  
**🇧🇷 Explicação:** Auto Scaling e RDS Multi-AZ oferecem redundância entre zonas de disponibilidade.

## ⚡ Domain 3: Design High-Performing Architectures

### ❓ Question 3  
**🇬🇧 Which two services improve database read performance?**  
**🇧🇷 Quais dois serviços melhoram o desempenho de leitura de banco de dados?**

A) RDS Read Replicas  
B) AWS Glue  
C) Amazon ElastiCache  
D) AWS WAF  
E) AWS CodeBuild

**✅ Answers: A, C**  
**🇬🇧 Explanation:** Read replicas offload traffic; ElastiCache provides low-latency in-memory reads.  
**🇧🇷 Explicação:** Read replicas reduzem o tráfego; ElastiCache oferece leituras em memória com baixa latência.

## 💸 Domain 4: Design Cost-Optimized Architectures

### ❓ Question 4  
**🇬🇧 Which two strategies help reduce AWS compute costs?**  
**🇧🇷 Quais duas estratégias ajudam a reduzir custos com computação na AWS?**

A) Use Reserved Instances  
B) Disable Auto Scaling  
C) Use Spot Instances for flexible workloads  
D) Use only On-Demand Instances  
E) Keep instances running at 100% capacity

**✅ Answers: A, C**  
**🇬🇧 Explanation:** Reserved and Spot Instances reduce costs for predictable and flexible workloads.  
**🇧🇷 Explicação:** Instâncias Reservadas e Spot reduzem custos para cargas previsíveis e flexíveis.
