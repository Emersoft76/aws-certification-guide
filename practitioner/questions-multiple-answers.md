## 🧠 Domain 1: Cloud Concepts | Conceitos de Nuvem

### ❓ Question 1
**🇬🇧 What are two advantages of cloud computing?**  
**🇧🇷 Quais são duas vantagens da computação em nuvem?**

A) High upfront investment  
B) Elasticity  
C) Global infrastructure  
D) Manual provisioning  
E) Single region limitation

**✅ Answers: B, C**  
**🇬🇧 Explanation:** Cloud computing offers elasticity and a global infrastructure for scalability and reach.  
**🇧🇷 Explicação:** A computação em nuvem oferece elasticidade e uma infraestrutura global para escalabilidade e alcance.

## 🔐 Domain 2: Security and Compliance | Segurança e Conformidade

### ❓ Question 2
**🇬🇧 Which two AWS services help monitor and audit activity?**  
**🇧🇷 Quais dois serviços da AWS ajudam a monitorar e auditar atividades?**

A) CloudWatch  
B) AWS Config  
C) AWS Shield  
D) Route 53  
E) Amazon S3

**✅ Answers: A, B**  
**🇬🇧 Explanation:** CloudWatch and AWS Config help track and visualize activity and configuration changes.  
**🇧🇷 Explicação:** O CloudWatch e o AWS Config ajudam a rastrear e visualizar atividades e alterações de configuração.

## ☁️ Domain 3: Cloud Technology and Services | Tecnologia e Serviços da Nuvem

### ❓ Question 3
**🇬🇧 Which two AWS services are used for decoupling applications?**  
**🇧🇷 Quais dois serviços da AWS são usados para desacoplar aplicações?**

A) AWS S3  
B) AWS Lambda  
C) Amazon SQS  
D) AWS SNS  
E) EC2

**✅ Answers: C, D**  
**🇬🇧 Explanation:** SQS (queues) and SNS (pub/sub) are commonly used for decoupling application components.  
**🇧🇷 Explicação:** SQS (filas) e SNS (publicação/assinatura) são usados para desacoplar componentes de aplicações.

## 💰 Domain 4: Billing, Pricing and Support | Faturamento, Preços e Suporte

### ❓ Question 4
**🇬🇧 Which two tools help manage and control AWS costs?**  
**🇧🇷 Quais duas ferramentas ajudam a gerenciar e controlar custos na AWS?**

A) AWS Budgets  
B) Trusted Advisor  
C) AWS Lambda  
D) Cost Explorer  
E) IAM Roles

**✅ Answers: A, D**  
**🇬🇧 Explanation:** AWS Budgets allows cost control through alerts, and Cost Explorer analyzes usage and trends.  
**🇧🇷 Explicação:** O AWS Budgets permite o controle de custos por alertas, e o Cost Explorer analisa o uso e tendências.
