## 🔐 Domain 1: Design Secure Architectures

### ❓ Question 1  
**🇬🇧 What service enables you to securely manage encryption keys for AWS services and applications?**  
**🇧🇷 Qual serviço permite gerenciar chaves de criptografia de forma segura para serviços e aplicações AWS?**

A) IAM  
B) AWS Secrets Manager  
C) AWS KMS  
D) AWS Shield

**✅ Answer: C**  
**🇬🇧 Explanation:** AWS Key Management Service (KMS) allows you to create, manage, and control encryption keys.  
**🇧🇷 Explicação:** O AWS KMS permite criar, gerenciar e controlar chaves de criptografia com segurança.

## ♻️ Domain 2: Design Resilient Architectures

### ❓ Question 2  
**🇬🇧 Which AWS feature enables you to maintain application availability by automatically replacing unhealthy instances?**  
**🇧🇷 Qual recurso da AWS permite manter a disponibilidade do aplicativo substituindo automaticamente instâncias com falha?**

A) Elastic Load Balancer  
B) Auto Scaling Group  
C) Route 53  
D) Amazon Inspector

**✅ Answer: B**  
**🇬🇧 Explanation:** Auto Scaling automatically replaces unhealthy EC2 instances to maintain availability.  
**🇧🇷 Explicação:** O Auto Scaling substitui automaticamente instâncias EC2 com falha para manter a disponibilidade.

## ⚡ Domain 3: Design High-Performing Architectures

### ❓ Question 3  
**🇬🇧 What AWS service is best for caching frequently accessed, read-heavy data to reduce latency?**  
**🇧🇷 Qual serviço AWS é ideal para cache de dados frequentemente acessados, com alta leitura, para reduzir a latência?**

A) Amazon Aurora  
B) Amazon RDS  
C) Amazon ElastiCache  
D) AWS Glue

**✅ Answer: C**  
**🇬🇧 Explanation:** ElastiCache provides in-memory caching using Redis or Memcached to accelerate data access.  
**🇧🇷 Explicação:** O ElastiCache oferece cache em memória usando Redis ou Memcached para acelerar o acesso aos dados.

## 💸 Domain 4: Design Cost-Optimized Architectures

### ❓ Question 4  
**🇬🇧 Which AWS service allows you to analyze past costs and usage and forecast future spending?**  
**🇧🇷 Qual serviço AWS permite analisar custos e uso passados e prever gastos futuros?**

A) AWS Cost Explorer  
B) AWS Budgets  
C) AWS Trusted Advisor  
D) AWS Pricing Calculator

**✅ Answer: A**  
**🇬🇧 Explanation:** Cost Explorer provides visual tools to understand and project AWS usage and costs.  
**🇧🇷 Explicação:** O Cost Explorer fornece ferramentas visuais para entender e prever o uso e os custos da AWS.
