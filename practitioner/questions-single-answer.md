## 🧠 Domain 1: Cloud Concepts | Conceitos de Nuvem

### ❓ Question 1
**🇬🇧 What is a key benefit of cloud computing?**  
**🇧🇷 Qual é um benefício chave da computação em nuvem?**

A) High upfront costs  
B) Limited scalability  
C) Pay-as-you-go pricing  
D) Manual provisioning

**✅ Answer: C**  
**🇬🇧 Explanation:** Cloud computing offers a pay-as-you-go pricing model, reducing upfront costs.  
**🇧🇷 Explicação:** A computação em nuvem oferece um modelo de pagamento conforme o uso, reduzindo os custos iniciais.

## 🔐 Domain 2: Security and Compliance | Segurança e Conformidade

### ❓ Question 2
**🇬🇧 Who is responsible for configuring security groups in AWS?**  
**🇧🇷 Quem é responsável por configurar os grupos de segurança na AWS?**

A) AWS  
B) Customer  
C) Third-party vendor  
D) Internet Service Provider

**✅ Answer: B**  
**🇬🇧 Explanation:** Under the shared responsibility model, customers are responsible for configuring security settings.  
**🇧🇷 Explicação:** No modelo de responsabilidade compartilhada, os clientes são responsáveis por configurar as definições de segurança.

## ☁️ Domain 3: Cloud Technology and Services | Tecnologia e Serviços da Nuvem

### ❓ Question 3
**🇬🇧 Which AWS service is used for object storage?**  
**🇧🇷 Qual serviço da AWS é usado para armazenamento de objetos?**

A) Amazon EBS  
B) Amazon S3  
C) Amazon RDS  
D) Amazon EC2

**✅ Answer: B**  
**🇬🇧 Explanation:** Amazon S3 is designed for storing and retrieving any amount of data at any time.  
**🇧🇷 Explicação:** O Amazon S3 é projetado para armazenar e recuperar qualquer quantidade de dados a qualquer momento.

## 💰 Domain 4: Billing, Pricing and Support | Faturamento, Preços e Suporte

### ❓ Question 4
**🇬🇧 Which AWS tool helps estimate monthly costs?**  
**🇧🇷 Qual ferramenta da AWS ajuda a estimar os custos mensais?**

A) AWS Cost Explorer  
B) AWS Pricing Calculator  
C) AWS Budgets  
D) AWS Trusted Advisor

**✅ Answer: B**  
**🇬🇧 Explanation:** AWS Pricing Calculator allows users to estimate their monthly AWS costs.  
**🇧🇷 Explicação:** O AWS Pricing Calculator permite que os usuários estimem seus custos mensais na AWS.
