# 🔐 Domain 2: Security and Compliance | Segurança e Conformidade

> 🇬🇧 This section explores the foundational security concepts in AWS, the shared responsibility model, core security services, and compliance programs.  
> 🇧🇷 Esta seção explora os conceitos fundamentais de segurança na AWS, o modelo de responsabilidade compartilhada, serviços principais de segurança e programas de conformidade.

---

## ✅ 2.1 – Shared Responsibility Model | Modelo de Responsabilidade Compartilhada

### 🇬🇧
- **AWS is responsible for "Security OF the Cloud"** (hardware, infrastructure, network).
- **Customer is responsible for "Security IN the Cloud"** (data, users, configurations).

### 🇧🇷
- **A AWS é responsável pela "Segurança DA Nuvem"** (hardware, infraestrutura, rede).
- **O cliente é responsável pela "Segurança NA Nuvem"** (dados, usuários, configurações).

---

## ✅ 2.2 – AWS Security Pillars | Pilares de Segurança da AWS

### 🇬🇧
- **Identity and Access Management (IAM):** Control who can access what.
- **Encryption:** Data at rest and in transit (KMS, S3 encryption).
- **Network Protection:** Security Groups, NACLs, VPC.
- **Monitoring & Logging:** CloudTrail, CloudWatch, AWS Config.
- **DDoS Protection:** AWS Shield and WAF.

### 🇧🇷
- **Gerenciamento de Identidade e Acesso (IAM):** Controle de acesso granular.
- **Criptografia:** Dados em repouso e em trânsito (KMS, criptografia S3).
- **Proteção de Rede:** Grupos de Segurança, NACLs, VPC.
- **Monitoramento e Logs:** CloudTrail, CloudWatch, AWS Config.
- **Proteção contra DDoS:** AWS Shield e WAF.

---

## ✅ 2.3 – AWS Compliance Programs | Programas de Conformidade da AWS

### 🇬🇧
- AWS adheres to certifications like:
  - ISO 27001, SOC 1/2/3, PCI-DSS, GDPR, HIPAA, FedRAMP.

### 🇧🇷
- A AWS está em conformidade com certificações como:
  - ISO 27001, SOC 1/2/3, PCI-DSS, GDPR, HIPAA, FedRAMP.

**Service for compliance information:**
- 🇬🇧 **AWS Artifact:** Access compliance reports and agreements.
- 🇧🇷 **AWS Artifact:** Acesse relatórios e acordos de conformidade.

---

## ✅ 2.4 – Security Best Practices | Boas Práticas de Segurança

### 🇬🇧
- Enable MFA for all users
- Use IAM roles instead of long-term credentials
- Apply the least privilege principle
- Monitor with CloudTrail and AWS Config
- Use AWS Organizations for central governance

### 🇧🇷
- Ative MFA para todos os usuários
- Use funções IAM em vez de credenciais de longo prazo
- Aplique o princípio do menor privilégio
- Monitore com CloudTrail e AWS Config
- Use AWS Organizations para governança centralizada
